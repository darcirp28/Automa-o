Não foi possível carregar os dados pelo app da Web configurado. Confira:
  • Se CONFIG.WEBAPP_URL (no topo do <script> deste arquivo) é exatamente a "URL do app da Web" mostrada ao implantar - terminada em /exec.
  • Se você está logado, neste navegador, com uma conta Google da empresa (ex: @bling.com.br) - a implantação exige login quando "Qualquer pessoa" não está disponível.
  • Se o seu e-mail está na propriedade ALLOWED_VIEWERS do script (se ela estiver definida, só os e-mails listados lá recebem os dados).
  • Se CONFIG.WEBAPP_TOKEN aqui é idêntico à propriedade DASHBOARD_TOKEN do script (ou se ambos estão em branco).
  • Se você gerou uma nova implantação depois da última alteração no script (salvar sozinho não republica).

Causa mais comum: a busca "de fundo" não leva o seu login do Google quando o dashboard está em outro site (como o GitHub Pages). Clique no botão abaixo para autorizar em uma janela - ela abre, confirma seu login e fecha sozinha.

Veja o passo a passo completo no comentário "API PARA O DASHBOARD" no topo do arquivo ExportarTicketsPE.gs.
Não foi possível carregar os dados da planilha. Isso geralmente acontece porque a planilha não está compartilhada publicamente para leitura. Você tem duas opções:
  • Recomendado (quando sua organização não permite "Qualquer pessoa com o link"): implante a função doGet incluída em ExportarTicketsPE.gs como um app da Web do Google Apps Script e preencha CONFIG.WEBAPP_URL neste arquivo - veja o passo a passo no comentário "API PARA O DASHBOARD" no topo daquele arquivo.
  • Ou, se sua conta permitir: abra a planilha → Compartilhar → Acesso geral → selecione "Qualquer pessoa com o link", papel Leitor.
Atenção com a segunda opção: ela torna a planilha (com dados de clientes e descrições) acessível a qualquer pessoa com o link, mesmo com o dashboard em um repositório privado.
